# INI-006 — Pilot Proposal
**Pilot:** 7B Sovereign Uzbek-Russian LLM — Phase 1 Government API
**Duration:** 12 months | **Contract:** $12,000,000 (UZ-TF-2026-011)

## Scope
- 7B parameter base model: Russian-foundation + Uzbek instruction tuning
- Script coverage: Uzbek-Latin (primary), Uzbek-Cyrillic (legacy), Russian (government domain)
- Domain specialization: legal, citizen services, healthcare, education
- Deployment: UzCloud government API (multi-tenant serving INI-002, INI-003, INI-008, INI-011)
- Co-publication: open benchmark + training methodology with NUU AI Cluster

## Success Metrics (Binding)
| Metric | Target |
|---|---|
| UZ language NLP benchmark score | ≥80% on co-published evaluation set |
| Russian benchmark vs. Yandex GPT | Within ±10% on UZ-relevant tasks |
| Uzbek-Cyrillic / Latin parity | Within ±5% accuracy |
| UzCloud API deployment latency | ≤500ms p95 |
| NUU benchmark co-publication | Published and open-licensed by Month 6 |

## Deliverables
1. 7B sovereign LLM weights (state-owned, licensed under terms agreed with AI Center)
2. Training pipeline code — transferable to AI Center team
3. UzCloud government API — serving downstream verticals
4. Open benchmark dataset + evaluation protocol
5. Methodology transfer package — AI Center team trains independently from Year 2

## Conversion Path
Year 2: 13B parameter upgrade; expanded domain corpus. Year 3: private-sector license (banking, telco, retail). Downstream: all INI-002, -003, -008, -011, -012 contracts use this LLM as horizontal layer. 3-year revenue: $35M.
