# INI-004 — Pilot Proposal
**Pilot:** Tax Risk-Scoring AI — Tashkent City STC Office
**Duration:** 9 months | **Contract:** $3,200,000 (UZ-T-2026-010)

## Scope
- ~200,000 legal-entity taxpayers in Tashkent City STC
- E-invoice graph construction: vendor-customer relationship graph for all registered entities
- Anomaly detection: round-trip transactions, valuation outliers, shell-company patterns, broker-network anomalies
- Audit-selection model: ranked audit list with confidence scores and explainability rationale
- Inspector dashboard: Russian-Uzbek bilingual, integrated with STC case management system

## Success Metrics (Binding)
| Metric | Target |
|---|---|
| Audit-selection precision improvement | ≥40% vs. status quo |
| Annualized tax recovery (pilot batch) | ≥$30M from Tashkent pilot |
| Inspectors trained on dashboard | ≥50 |
| False positive rate on audit flags | ≤10% |
| UzCloud data residency audit | Zero foreign data egress |

## Deliverables
1. E-invoice graph + anomaly detection model (UzCloud-deployed)
2. Audit-selection ranking engine with explainability
3. Russian-Uzbek bilingual inspector dashboard
4. Training documentation for GNK analytics team
5. Pilot evaluation report with ROI measurement

## Conversion Path
Year 2: 14 oblast STC offices. Year 3: State Customs Committee (customs risk-scoring, INI-005 cross-sell) and Anti-Monopoly Committee (cartel detection). 3-year revenue: $24M.
