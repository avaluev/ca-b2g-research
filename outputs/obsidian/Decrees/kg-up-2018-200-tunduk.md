# On Approval of Requirements for Information System Interaction in the 'Tunduk' Inter-Agency Electronic Interaction System

_Об утверждении Требований к взаимодействию информационных систем в системе межведомственного электронного взаимодействия «Тундук»_

## Provisions on AI / digital

Foundational technical requirements for Tunduk inter-agency data exchange system. Establishes API standards, data formats, and security requirements for government information system interoperability. Kyrgyzstan's equivalent of Estonia's X-Road (forked from Cybernetica UXP). Now under УДП after April 2026 reorganization.
