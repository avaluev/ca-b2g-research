# Global Gateway Central Asia — Digital and Connectivity Package

**Donor**: EU  •  **Country**: BOTH  •  **Status**: active

## AI / digital relevance

EU's Global Gateway digital connectivity package for Central Asia announced at April 2025 Samarkand summit. Includes: €60M EIB-EU package for SES satellite connectivity (rural CA populations in UZ, KG, KZ, TJ); digital trade facilitation; cybersecurity norms alignment. Broader package stated at €12B but majority is private mobilization. Digital components estimated €60-65M public funds. Covers connectivity infrastructure underpinning all digital services.
