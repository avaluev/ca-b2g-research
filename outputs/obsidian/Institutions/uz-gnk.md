# State Tax Committee of the Republic of Uzbekistan

**RU**: Государственный налоговый комитет Республики Узбекистан  
**Local**: O'zbekiston Respublikasi Davlat soliq qo'mitasi  

## Mandate (AI / digital)

Operates Soliq.uz electronic tax portal. Implements e-invoicing (ЭДО) mandatory for VAT payers. Key buyer for AI-assisted tax audit, e-invoice analytics, fraud detection AI. High-volume transaction data environment — prime AI use case.

**Reports to**: [[Institutions/uz-moef|UZ-MOEF]]

## Recent decisions (12 months)

- E-invoicing mandatory rollout for all VAT payers
- AI tax fraud detection pilot programs
- Soliq.uz portal integration with EPIGU citizen portal
