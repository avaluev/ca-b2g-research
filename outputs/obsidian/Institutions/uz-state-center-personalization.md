# State Center for Personalization (under Ministry of Internal Affairs)

**RU**: Государственный центр персонализации при МВД Республики Узбекистан  
**Local**: Davlat Shaxslashtirish Markazi  

## Mandate (AI / digital)

Operates biometric ID card production and issuance. Maintains biometric database (fingerprints, digital photos, chip data). Provides biometric verification services to MyID and EPIGU. Key operational arm for identity infrastructure.

**Reports to**: [[Institutions/uz-mvd|UZ-MVD]]

## Recent decisions (12 months)

- Mandatory biometric ID rollout (УП-6065) — 100% population coverage program
- MyID biometric verification integration
- Mobile-ID chip compatibility upgrade (2025-2026)
