# Financial Services Regulatory Authority of the Kyrgyz Republic (SRFR / FSA)

**RU**: Служба регулирования и надзора финансового рынка при Правительстве КР (СРНФР / ФСА)  
**Local**: КР Финансы рыногун жөнгө салуу жана көзөмөлдөө кызматы  

## Mandate (AI / digital)

Regulates virtual assets (crypto), stablecoins (USDKG), non-bank financial services digital transformation. Oversees crypto exchange licensing. Key regulator for any blockchain/crypto AI compliance tool. Post-Japarov consolidation: expanded mandate for virtual assets under Цифровой кодекс 2025.

**Reports to**: [[Institutions/kg-cabinet|KG-CABINET]]

## Recent decisions (12 months)

- USDKG stablecoin regulatory framework (Цифровой кодекс 2025)
- Virtual assets licensing under new Digital Code
- Crypto exchange oversight — AI compliance tool procurement
- AML/KYC requirements for crypto/virtual asset operators
