# State Registration Service of the Kyrgyz Republic

**RU**: Государственная регистрационная служба Кыргызской Республики  
**Local**: Кыргыз Республикасынын Мамлекеттик каттоо кызматы  

## Mandate (AI / digital)

Biometric identification database, civil registration, company/property registration. Interfaces with Tunduk for identity verification. Key buyer for biometric AI verification, e-registry modernization. Population registry underpins all e-government services.

**Reports to**: [[Institutions/kg-cabinet|KG-CABINET]]

## Recent decisions (12 months)

- Digital civil registration system (birth, death, marriage) modernization
- Biometric identity verification integration with Tunduk platform
- Property registry digitalization
