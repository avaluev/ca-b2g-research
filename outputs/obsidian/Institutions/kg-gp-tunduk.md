# State Institution 'Tunduk' — Inter-Agency Electronic Interaction System (under UDP after April 2026)

**RU**: Государственное учреждение «Тундук» — система межведомственного электронного взаимодействия (под УДП с апреля 2026)  
**Local**: «Тундук» мамлекеттик мекемеси  

## Mandate (AI / digital)

Kyrgyzstan's X-Road equivalent. 800+ government information systems connected. All inter-agency data exchange flows through Tunduk. CRITICAL infrastructure layer — any AI system needing government data must integrate via Tunduk API. Post-April 2026 now under UDP (transferred from dissolved Mintsifry). CW-008 (Tunduk modernization, Estonian EGA-led, EU-funded).

**Reports to**: [[Institutions/kg-udp|KG-UDP]]

## Recent decisions (12 months)

- Transferred to UDP oversight after April 2026 Mintsifry dissolution
- CW-008: Tunduk modernization with Estonian EGA advisory (EU-funded)
- 800+ information systems connected
- New API standards development under Цифровой кодекс 2025
- Procurement window for Tunduk technical upgrade open
