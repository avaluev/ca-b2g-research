# UNICON.UZ State Unitary Enterprise (Cybersecurity Center)

**RU**: ГУП UNICON.UZ (Центр кибербезопасности Узбекистана)  
**Local**: UNICON.UZ DUK  

## Mandate (AI / digital)

National cybersecurity center. Operates CERT (Computer Emergency Response Team). Cybersecurity certification of state information systems. Any foreign vendor's AI system sold to Uzbekistan government must pass UNICON certification. Critical gatekeeper institution.

**Reports to**: [[Institutions/uz-mintsifry|UZ-MINTSIFRY]]

## Recent decisions (12 months)

- CERT operations for state cybersecurity incident response
- ЗРУ-764 / ЗРУ-964 implementation — cybersecurity certification of state IS
- AI system security assessment framework development under УП-189
