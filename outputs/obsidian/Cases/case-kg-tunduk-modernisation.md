# Kyrgyzstan Tunduk Interoperability Platform Modernisation (EU-Funded)

**Origin**: Kyrgyzstan  •  **Year**: 2022  •  **Sector**: Cross-cutting

## Problem solved

KG Tunduk (GP Tunduk) was established as an X-Road fork in 2018 but ran on X-Road version 6.x while X-Road 7.x introduced REST API support, improved performance, and enhanced audit capabilities. The EU DigiConnect4CA programme funded a Tunduk modernisation to upgrade to current X-Road standards, expand connected agencies, and integrate with the Estonian Government Technology Agency (EGA) ecosystem for future cross-border services.

## Architecture

EGA-led project: upgrade Tunduk security servers to X-Road 7.x, onboard 20 additional government agencies (from current 30 to 50+), deploy X-Road Central Server on KG government cloud infrastructure, integrate Tunduk with KG single digital identity (GRS biometric ID as OIDC provider). EU EU4Digital project provides technical assistance. EGA seconded specialists to Bishkek for 6-month deployment support. Long-term: Tunduk inter-connection with Estonian X-Road instances for potential cross-border pilot.

## UZ transferability (8/10)

UZ should negotiate an identical EGA advisory programme for UZINTERSTATE modernisation. The KG model — EGA specialist secondment + EU funding + X-Road upgrade — is directly applicable. UZ's larger scale would require a larger team and longer timeline but same architecture. EU DigiConnect4CA has UZ components. This is an active procurement opportunity for EGA-certified implementation partners.

## KG transferability (9/10)

This IS the KG case — ongoing. Phase 3 (cross-border integration pilot with Estonia + UZ) is the next procurement. The AI service layer on top of modernised Tunduk (Bürokratt-equivalent bot + open data portal) is the logical follow-on. This is the foundational infrastructure enabling multiple other KG digital services.
