# Indonesia Satu Data Indonesia Open Data Platform

**Origin**: Indonesia  •  **Year**: 2019  •  **Sector**: Cross-cutting

## Problem solved

Indonesia's 130+ ministries and 500+ districts each maintained separate data portals with incompatible formats, preventing whole-of-government analytics and creating data duplication. Satu Data Indonesia (One Data Indonesia) Presidential Regulation mandated all government data to be published in open, machine-readable format through a unified national data portal.

## Architecture

Satu Data (data.go.id): national open data portal + mandatory data governance framework. Presidential Regulation 39/2019 mandated: data principals (agencies) to publish all non-sensitive data in standard format, data stewards (provinces) to aggregate regional data, and a national data committee to set standards. Technical stack: CKAN-based data portal, API layer, GIS integration for spatial datasets. AI component: dataset similarity detection (deduplication), automated data quality scoring, metadata completeness checker. Government analytics: Pusdatin (Government Data Centre) builds dashboards on Satu Data feeds.

## UZ transferability (8/10)

UZ has data.gov.uz portal but it lacks presidential mandate for mandatory data publication and machine-readable standards. Indonesia's Presidential Regulation 39/2019 is the policy model. CKAN is already deployed in some Central Asian open data portals. Budget: $2-3M for UZ Satu Data equivalent + presidential decree for mandatory agency compliance. World Bank digital governance project donor pathway.

## KG transferability (8/10)

KG has data.gov.kg in early stages. Presidential mandate model via Kyrgyz Cabinet Resolution could accelerate. Цифровой Кодекс (2025) includes open data provisions. CKAN deployment for KG national data portal: $1-2M. Strong donor interest: EU, World Bank, USAID-successor all fund open government data programmes.
