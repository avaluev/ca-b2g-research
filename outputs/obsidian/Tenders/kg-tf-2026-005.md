# [FORECAST] AML System for Commercial Banks — Digital Code Compliance Upgrade

**Issuer**: [[Institutions/kg-fsa|KG-FSA]]  •  **Deadline**: 2026-12-31  •  **Value**: $1,800,000

## Scope

FORECAST: Digital Code compliance requirements for fintech and banking sector. Scope: AI-based AML transaction monitoring upgrade for all licensed banks, KYC automation with digital ID integration, virtual asset monitoring integration (post-USDKG), cross-border transaction screening, reporting automation to FSA and National Bank. Serves 22 licensed commercial banks.

**Win probability (medium)**: Regulatory-driven procurement — mandate creates non-negotiable demand. Existing bank-level AML vendors (FICO, Temenos, Finastra) have incumbent relationships in some KG banks. New digital asset monitoring is a gap. Boutique regtech firms with CIS banking experience (Intersoft, ComplianceTech) are competitive.
