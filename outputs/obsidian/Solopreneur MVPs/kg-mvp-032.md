# WeatherFarmAlertKG

_Free SMS+Telegram weather alerts for Kyrgyz farmers — frost, hail, mudflow — using ECMWF open data_

## Pain point

Farmers lose crops to frost/hail/mudflow with no warning. State Met Service generic. Mountain regions unique disaster risk.

**Evidence**: https://meteo.kg/


**Target customer**: Smallholder farmers 30-65 in Issyk-Kul, Naryn, Talas


## Monetization

- **Model**: donation
- **Price point**: $0.00
- **Year-1 target**: $4,000
- **Year-3 target**: $40,000


## MVR plan (free_tool)

- **Build time**: 6 days
- **Build cost**: $50

**Steps:**
- [ ] Pull ECMWF Open Data via Open-Meteo
- [ ] Telegram bot + SMS via Twilio
- [ ] Per-pin alert rule
- [ ] AKDN/WB grant pitch ($25K)
- [ ] Soft-launch in Naryn + Issyk-Kul farmer Telegram


## Validation

- **Signal target**: 800 farmer signups in 60 days
- **Window**: 60 days
- **Channels**: Naryn farmer Telegram, Issyk-Kul farmer Telegram, AKDN partner network


**Tech stack**: Open-Meteo, Telegram Bot, Twilio

**Capability required**: Russian + Kyrgyz, weather API


## Moat potential

Farmer audience; donor-grant; cross-promo.

## Risks

- **False alarms** — _Mitigation_: Multi-source threshold
- **SMS cost** — _Mitigation_: Telegram primary
- **State competitor** — _Mitigation_: Lean on per-pin
