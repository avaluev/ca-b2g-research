# BusScheduleUZ

_Free tool aggregating real-time Tashkent bus + metro schedules + GPS tracking, in Russian and Uzbek_

## Pain point

Tashkent metro + bus schedules are official-but-buried. Yandex Maps coverage is partial. Commuters wait 10-15 min in summer heat.

**Evidence**: https://www.spot.uz/ru/category/biznes/transport/


**Target customer**: Tashkent commuters 18-55 using public transit daily; secondary: tourists using public transit


## Monetization

- **Model**: ad
- **Price point**: $100.00
- **Year-1 target**: $6,000
- **Year-3 target**: $50,000


## MVR plan (ad_booking)

- **Build time**: 7 days
- **Build cost**: $60

**Steps:**
- [ ] Build Telegram bot + web app fed by Tashkent Transit open data
- [ ] Add user-reported delays
- [ ] Sponsored slot for ride-hailing alternatives
- [ ] Soft-launch via spot.uz + TashkentMetro Telegram
- [ ] Add tip jar


## Validation

- **Signal target**: 3,000 unique users + 1 sponsor in 60 days
- **Window**: 60 days
- **Channels**: spot.uz transport, Tashkent commuter Telegram, Tashkent expat WhatsApp


**Tech stack**: Telegram Bot, Carrd, Notion (data)

**Capability required**: Russian + Uzbek-Latin, data integration


## Moat potential

Tashkent commuter audience compounds; can extend to other oblasts.

## Risks

- **Open data limited** — _Mitigation_: Crowdsource from users
- **Govt absorbs** — _Mitigation_: Lean on UX speed
- **Low ad demand** — _Mitigation_: Tip jar baseline
