# PayrollBuddyUZ

_SaaS for SMEs: import employee list, get monthly payroll calc with all UZ taxes/social contributions_

## Pain point

SMEs use Excel templates for payroll. Errors cause penalty. Buxgalter Plus is enterprise; Kassa.uz is invoicing-only. Self-employed accountants charge $30-50/mo per company.

**Evidence**: https://buxgalter.uz/


**Target customer**: Tashkent SMEs (5-30 employees) currently using Excel + 1 part-time accountant; secondary: solo accountants serving 5-10 SMEs
