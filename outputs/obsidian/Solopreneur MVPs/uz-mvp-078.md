# HomestayAdminUZ

_Wizard-of-Oz: helps Uzbek B&B/homestay owners list on Booking.com + Airbnb, handle guest comms in English_

## Pain point

Samarkand/Bukhara/Khiva homestay owners (1,000+) are local Uzbek-speakers; Booking.com listing requires English + photos. Many lose bookings due to communication barrier.

**Evidence**: https://uzbektourism.uz/


**Target customer**: Homestay/B&B owners 35-60 in Samarkand, Bukhara, Khiva, Tashkent old city — Russian fluent but English limited


## Monetization

- **Model**: services
- **Price point**: $30.00
- **Year-1 target**: $16,000
- **Year-3 target**: $100,000


## MVR plan (wizard_of_oz)

- **Build time**: 7 days
- **Build cost**: $100

**Steps:**
- [ ] Templates for Booking.com + Airbnb optimized listings
- [ ] Telegram bot intake: photos + features + price
- [ ] Founder + 1 part-time English coach handle listing + guest comms
- [ ] $30/listing + 10% bookings commission
- [ ] Soft-launch via Samarkand homestay WhatsApp via researcher contacts


## Validation

- **Signal target**: 10 paid listings + 2 commission deals in 60 days
- **Window**: 60 days
- **Channels**: Samarkand homestay WhatsApp, Bukhara hospitality Telegram, Khiva guesthouse network


**Tech stack**: Telegram Bot, Notion, Click + Stripe

**Capability required**: Russian + Uzbek-Latin + English, Booking.com/Airbnb host experience, operations


## Moat potential

Host + booking-channel network compounds; can scale to Kyrgyzstan and Tajikistan.

## Risks

- **Channel rule changes** — _Mitigation_: Multi-channel strategy
- **Operational burden** — _Mitigation_: Cap at 30 hosts, then productize
- **Trust** — _Mitigation_: Reference customers from researcher contacts
