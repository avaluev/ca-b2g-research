# KyrgyzHistoryGame

_Free Telegram quiz bot teaching Kyrgyz history and culture to Grade 5-8 students with daily 10-question challenges_

## Pain point

Schools have weak history retention. Kids prefer mobile games. AKDN supports edutainment.

**Evidence**: https://www.akdn.org/


**Target customer**: Grade 5-8 students 10-14 across KG; parents


## Monetization

- **Model**: freemium
- **Price point**: $2.00
- **Year-1 target**: $5,000
- **Year-3 target**: $40,000


## MVR plan (free_tool)

- **Build time**: 7 days
- **Build cost**: $50

**Steps:**
- [ ] Compile 400 KG history questions
- [ ] Telegram bot daily quiz + leaderboard
- [ ] Free + leaderboard, $2/mo parent dashboard + tracking
- [ ] Mbank subscription
- [ ] Soft-launch via Bishkek parent + AKDN partner schools


## Validation

- **Signal target**: 400 daily-active + 40 paid in 60 days
- **Window**: 60 days
- **Channels**: Bishkek parent Telegram, AKDN partners, kaktus.media education


**Tech stack**: Telegram Bot, Supabase, Mbank

**Capability required**: Russian + Kyrgyz, history domain


## Moat potential

Question bank + community; donor-grant.

## Risks

- **Accuracy** — _Mitigation_: Historian advisor
- **Retention** — _Mitigation_: Leaderboard + parent dashboard
- **Govt competitor** — _Mitigation_: Game design
