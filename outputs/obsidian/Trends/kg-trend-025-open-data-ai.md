# Open government data AI analytics platform (data.gov.kg) under Digital Code open data mandate

> [!important] Killer app
> KG Open Data Intelligence Platform: AI-powered national data catalog unifying 200+ government datasets via Tunduk; automated data quality and freshness scoring; natural language search in Kyrgyz/Russian; API marketplace enabling private sector startups to build civic apps on government data — creating the open data foundation that transforms Kyrgyzstan from data silo to AI-ready government data ecosystem

## Drivers

- Digital Code 2025: Section IV on digital registries mandates open government data infrastructure
- UNDP open data/e-participation program in KG
- OSF (Open Society Foundation) civic tech programs — data.gov.kg needs analytics layer
- World Bank GovTech TA program includes open data component
- Digital Transformation Concept 2024-2028: open data as transparency pillar
