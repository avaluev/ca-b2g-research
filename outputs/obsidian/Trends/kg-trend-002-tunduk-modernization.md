# Tunduk inter-agency data exchange modernization under UDP governance (Estonia EGA-linked, EU-funded)

> [!important] Killer app
> Tunduk next-generation data exchange platform: upgrade from current batch-based API to real-time event-driven architecture; add AI-powered data quality scoring for incoming government datasets; create unified government API marketplace enabling private sector access to anonymized public datasets — transforming Tunduk from a compliance system into a data economy enabler for KG's 50+ active information systems

## Drivers

- KG-UP-2026: Tunduk transferred from Mintsifry to GP Infocom under UDP
- Tunduk is KG equivalent of Estonia's X-Road (technically forked from Cybernetica UXP)
- Digital Code 2025 (KG-LAW-2025-178) mandates Tunduk as the national ecosystem backbone
- EU Team Europe and EGA (Estonian Government Advisory) fund modernization — €12B Global Gateway for Central Asia includes KG component
- World Bank Digital CASA and KG Digital GovTech TA programs co-finance Tunduk
