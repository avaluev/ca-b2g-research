## WCAG 2.2 AA Checklist

|---|-----------|--------|---------|
| 1.1.1 | Non-text content | WARN | No `<img>` elements. OG image references `/og-default.png` which does not exist (file is `.svg`). |
| 1.3.1 | Info & Relationships | FAIL | All data tables lack `scope` on `<th>` cells. `<nav>` has no `aria-label`. Brand `<span>` should be `<a>` or `<strong>` inside a landmark. |

| 1.4.10 | Reflow | PASS | `max-width:880px` + `padding:24px 20px` with `flex-wrap:wrap` on nav. No fixed-width elements observed. |
| 1.4.11 | Non-text contrast | FAIL | Nav link focus ring: none defined. Table `border-bottom:#eaeaea` on white is 1.43:1 — purely decorative so not a violation, but the focus ring gap is. |

| 2.1.1 | Keyboard | FAIL | No skip-to-main-content link — first Tab target is the brand span (non-interactive). Nav has 15 links before main content; keyboard-only users must Tab through all 15 before reaching H1. |
| 2.4.1 | Bypass blocks | FAIL | No skip link present. |
| 2.4.4 | Link purpose | WARN | Footer link text is the raw URL (`github.com/avaluev/ca-b2g-research`) — acceptable in context, but `<a href="…">GitHub repository</a>` is better. Decree table uses "primary source" for every row without context — ambiguous in isolation. |
| 2.4.6 | Headings & labels | PASS | H1→H2→H3 hierarchy correct on all sampled pages. |
| 2.4.7 | Focus visible | FAIL | No `:focus-visible` rule in CSS. Browser default `outline` is `outline:0` on many system-ui themes. |
| 2.5.5 | Target size | FAIL | Nav links have `padding` only on their parent `nav` (`padding:12px 20px`) not on individual `<a>` elements — computed tap targets ~14 px tall. Minimum AA is 24×24 px. |

| 4.1.3 | Status messages | PASS | Static site, no dynamic content. |

## 15 HTML/CSS Patches

All patches apply to `scripts/render_site.py` unless noted.

### Patch 1 — Skip link HTML (add before `<header>`)

```python
# In render_page(), replace the opening <body> line:
# BEFORE:
<body>
<header class="nav"><nav>

# AFTER:
<body>
<a class="skip-link" href="#main-content">Skip to main content</a>
<header class="nav"><nav>
```

### Patch 12 — Brand span: make it a non-link heading or add `aria-hidden`

The brand "Central Asia B2G" is inside `<nav>` but is not a link — screen readers may announce it as a navigation item. Either link it to `/` or suppress it from the nav landmark.

```python
# BEFORE:
<span class="brand">Central Asia B2G</span>

# AFTER:
<a href="/" class="brand" aria-label="Central Asia B2G — home">Central Asia B2G</a>
```

### Patch 13 — `<span lang="ru">` for Russian-script content

Add a helper to the renderer and use it in table cells that contain Cyrillic text:

```python
def ru(text: str) -> str:
    """Wrap non-empty text in a Russian language span."""
    if not text:
        return ""
    return f'<span lang="ru">{escape(text)}</span>'
```

Apply in `decrees_page()` for `d.get('number')` and `institutions_page()` for `name_ru` column:

```python
# institutions table name_ru cell — BEFORE:
f"<td>{escape(i.get('name_ru') or '')}</td>"

# AFTER:
f"<td>{ru(i.get('name_ru') or '')}</td>"
```

```python
# decrees table number cell — BEFORE:
f"<td>{escape(d.get('number') or '')}</td>"

# AFTER:
f"<td>{ru(d.get('number') or '')}</td>"
```
