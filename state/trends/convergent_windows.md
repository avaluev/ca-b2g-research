# Convergent Windows — Top 15

**Definition**: A convergent window has ≥2 lens tags, ≥1 active decree, ≥1 named decision-maker, and either ≥1 active donor program OR confirmed state budget line, with ≥6 months of procurement window remaining.

**Ranking logic**: Windows are ranked by combined lens count, decree half-life urgency, budget certainty, and estimated contract value.
